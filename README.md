## Портфель та параметри

| Параметр | Значення |
|----------|----------|
| Активи | SPY (40%), VGK (20%), TLT (25%), GLD (15%) |
| Вартість портфеля | ~$24 390 (≈ 1 000 000 грн / 41 грн/$) |
| Період даних | 02.01.2020 → 30.12.2024 (1 257 торгових днів цін, 1 256 денних дохідностей) |
| Горизонти | 1 і 10 торгових днів |
| Рівні довіри | 95% і 99% |
| Кількість сценаріїв N | 100 000 у вебзастосунку; 1 000 000 для таблиць курсової (за правилом зупинки) |
| Seed | 42 |
| ν Стьюдент | 4 (оцінка ММП за дохідностями портфеля: ν̂ = 3,83) |

> **Примітка:** Валютний ризик гривні у базовій моделі не моделюється.
> Вартість портфеля виражена у доларовому еквіваленті.

## Ключові особистості внеску (оголошено в курсовій)

1. **Паралельне моделювання** — нормальний розподіл vs багатовимірний розподіл Стьюдента з тією самою коваріаційною матрицею (ν оцінено ММП) → кількісне порівняння занижування крайніх втрат при нормальному припущенні.
2. **Стрес-сценарій «збіг кореляцій»** — підвищення кореляцій до 0.9 та волатильностей ×1.5.
3. **Правило зупинки** — найменше N, починаючи з якого відносна зміна CVaR між сусідніми точками сітки стабільно < 1%.
4. **Відтворюваність** — фіксований `seed=42`, `numpy.random.default_rng`.
